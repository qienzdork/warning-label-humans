# Warning Label for Humans: One Line, Big Laugh

A single-line safety warning label that should come printed on every human
being, in the deadpan voice of a product warning. The program is
deterministic: running `python3 main.py` always writes the same line to
`/output/entry.txt` (or to `$OUTPUT_PATH` when set), stdlib only, no
network, no randomness.

The line: *"WARNING: Contains a human. Handle with care: it will agree to
your face, complain to everyone else, and call this 'being the bigger
person.'"*
